# 26.3 API migration notes

Mapping of Minecraft 1.21-era APIs to their 26.3 replacements, kept so the same
substitution can be applied quickly across the tree. Verified against
`fabric-26.3/build/mcapi/minecraft.jar` with `fabric-26.3/build/mcapi/inspect.py`.

## Applied (see `fabric-26.3/build/ci/api_map.py`)

| 1.21 API | 26.3 replacement |
| --- | --- |
| `BlockBehaviour#codec()`, `simpleCodec()`, `propertiesCodec()` | removed for blocks; delete block `CODEC`/`codec()` members |
| `Block#updateShape(state, direction, neighborState, world: LevelAccessor, pos, neighborPos)` | `updateShape(state, level: LevelReader, ticks: ScheduledTickAccess, pos, directionToNeighbour, neighbourPos, neighbourState, random: RandomSource)` |
| `Block#onRemove(state, level: Level, pos, newState, movedByPiston)` | `affectNeighborsAfterRemoval(state, level: ServerLevel, pos, movedByPiston)` (no `newState`) |
| `Containers.dropContentsOnDestroy(state, newState, level, pos)` | `Containers.dropContents(level, pos, container)` |
| `net.minecraft.world.item.UseAnim` | `net.minecraft.world.item.ItemUseAnimation` |
| `InputConstants.Type.KEYSYM` | `InputConstants.Type.KEYBOARD` |
| `net.minecraft.client.renderer.LightTexture.pack(b, s)` | `net.minecraft.util.LightCoordsUtil.pack(b, s)` |
| `GuiGraphics#renderTooltip(...)` | `GuiGraphicsExtractor#setTooltipForNextFrame(...)` |
| `BlockPos#bottomCenter` | `Vec3.atBottomCenterOf(pos)` |
| `DirectionProperty` | `EnumProperty<Direction>`, `EnumProperty.create(name, Direction::class.java)` |
| `RenderType.entityCutout/entitySolid/entityTranslucent/beaconBeam/waterMask/text/lightning(..)` | `RenderTypes.<same>(..)` in `net.minecraft.client.renderer.rendertype` |
| `Block#getCloneItemStack(level, pos, state)` | `getCloneItemStack(level, pos, state, includeData: Boolean)` |
| `Block#neighborChanged(state, level, pos, block, direction, moved)` | `neighborChanged(state, level, pos, block, orientation: Orientation, moved)` |
| `net.minecraft.advancements.critereon.*` | split: `net.minecraft.advancements.predicates.*` (predicates, `StatePropertiesPredicate`, `MinMaxBounds`) and `net.minecraft.advancements.triggers.*` (`CriterionTrigger`, `CriteriaTriggers`, `SimpleCriterionTrigger`) |
| `CriterionTrigger` / `SimpleCriterionTrigger<T, C>` | `CriterionTrigger<T : CriterionTriggerInstance>`; `SimpleCriterionTrigger<T : SimpleCriterionTrigger.SimpleInstance>`, `codec()` now declared by the interface |
| `SimpleCriterionTrigger.SimpleInstance#player()` returning `Optional<EntityPredicate>` | returns `Optional<Holder<LootItemCondition>>`; `EntityPredicate.wrap(...)` already produces that |
| `BuiltInRegistries.ENTITY_SUB_PREDICATE_TYPE` holding `MapCodec` | still `Registry<Codec<out EntitySubPredicate>>` |
| `ItemPredicate.Builder#of(item)` / `of(tag)` | `of(HolderGetter<Item>, itemLike)` / `of(HolderGetter<Item>, TagKey<Item>)` |
| `ItemPredicate.Builder#withSubPredicate(ItemSubPredicates.CUSTOM_DATA, ItemCustomDataPredicate(nbt))` | `withComponents(DataComponentMatchers(DataComponentExactPredicate.EMPTY, mapOf(DataComponentPredicates.CUSTOM_DATA to CustomDataPredicate(nbt))))` |
| unconstrained `T` in `Registry<T>`, `TagKey<T>`, `ResourceKey<T>`, `MemoryModuleType<U>` | these types are bounded by `T : Any` in 26.3, so every Kotlin generic that feeds them must declare `: Any` too |
| `SignItem(properties, standing, wall)` | removed; `StandingAndWallBlockItem(standing, wall, attachmentDirection, properties)` |
| `FoodProperties.Builder#usingConvertsTo(item)` | `Item.Properties#usingConvertsTo(item)` |
| `FoodProperties.Builder#fast()` | `Item.Properties#food(food, Consumable.builder().consumeSeconds(0.8F).build())` |
| `FoodProperties.Builder#effect(effect, probability)` | `Consumable.builder().onConsume(ApplyStatusEffectsConsumeEffect(effect, probability))` |
| `SmithingTemplateItem(appliesTo, ingredients, upgradeDescription, baseSlot, additionsSlot, icons, icons)` | `SmithingTemplateItem(appliesTo, ingredients, baseSlot, additionsSlot, icons, icons, properties)`; `createArmorTrimTemplate(properties)` only |
| `Direction#normal` (`Vec3i`) | private in 26.3; use the local `com.cobblemon.mod.common.util.normal` extension built from `stepX/stepY/stepZ` |
| `AbstractScrollArea#getScrollbarPosition()` | `scrollBarX()` |
| `Screen#renderBlurredBackground(partialTick)` | `extractBlurredBackground(context: GuiGraphicsExtractor)` |
| `ItemStack#typeHolder` (field) | `ItemStack#typeHolder()` (method) |
| `EntitySubPredicate` codecs registered by `CobblemonEntitySubPredicates` | `BuiltInRegistries.ENTITY_SUB_PREDICATE_TYPE` still holds `Codec<out EntitySubPredicate>`; a `MapCodec` source needs `.codec()` |
| `net.minecraft.client.model.BoatModel`, `ChestBoatModel` | `net.minecraft.client.model.object.boat.BoatModel`; `ChestBoatModel` is gone, use `BoatModel.createChestBoatModel()` |
| `net.minecraft.client.model.PlayerModel` | `net.minecraft.client.model.player.PlayerModel` |
| `net.minecraft.client.RecipeBookCategories` | `net.minecraft.world.item.crafting.RecipeBookCategories` |
| `net.minecraft.server.network.ServerPlayer` | `net.minecraft.server.level.ServerPlayer` |
| `net.minecraft.client.ParticleStatus` | `net.minecraft.server.level.ParticleStatus` |
| `net.minecraft.world.entity.vehicle.Boat` | `net.minecraft.world.entity.vehicle.boat.Boat` (same for `ChestBoat`) |
| `net.minecraft.world.entity.npc.*` | `net.minecraft.world.entity.npc.villager.*` (`Villager`, `VillagerData`, `VillagerProfession`, `VillagerType`) |
| `net.minecraft.world.entity.monster.Slime` | `net.minecraft.world.entity.monster.cubemob.Slime` |
| `net.minecraft.world.level.BlockAndTintGetter` | `net.minecraft.client.renderer.block.BlockAndTintGetter` |
| `net.minecraft.sound.SoundEvents` / `net.minecraft.stat.Stats` | `net.minecraft.sounds.SoundEvents` / `net.minecraft.stats.Stats` |
| `net.minecraft.client.gui.components.toasts.ToastComponent` | `net.minecraft.client.gui.components.toasts.ToastManager` |
| `com.mojang.blaze3d.platform.GlStateManager` | `com.mojang.renderpearl.backend.opengl.GlStateManager` |
| `BlockEntity#saveAdditional(CompoundTag, HolderLookup.Provider)` | `saveAdditional(output: ValueOutput)`; `loadAdditional(input: ValueInput)` |
| `CompoundTag#put(key, tag)` in a block entity | `output.putTag(key, tag)` (local extension in `CompoundTagExtensions.kt`) or `output.store(key, CompoundTag.CODEC, tag)` |
| `tag.getInt(k).orElse(d)` | `input.getIntOr(k, d)` (also `getFloatOr`, `getBooleanOr`, `getStringOr`, `getLongOr`) |
| `tag.contains(k)` in `loadAdditional` | no equivalent; use `read`/`getX` returning `Optional` or the `getXOr` default |
| `tag.remove(k)` | `output.discard(k)` |
| `NbtUtils.writeBlockPos` / `readBlockPos` | `output.store(k, BlockPos.CODEC, pos)` / `input.read(k, BlockPos.CODEC).orElse(null)` |
| `ContainerHelper.saveAllItems(tag, list, provider)` | `ContainerHelper.saveAllItems(output, list)` (same for `loadAllItems`) |
| `PlayerInventory`-style UUID helpers | new `ValueOutput.putUUID` / `ValueInput.getUUID` / `ValueInput.hasUUID` extensions backed by `UUIDUtil.CODEC` |
| GUI `PoseStack` | `GuiGraphicsExtractor#pose()` returns `org.joml.Matrix3x2fStack`: `pushPose`/`popPose` → `pushMatrix`/`popMatrix`, and `translate`/`scale` take two floats (the z argument is gone) |
| `GuiGraphics` | `net.minecraft.client.gui.GuiGraphicsExtractor` |
| `Screen#render(...)` | `extractRenderState(GuiGraphicsExtractor, mouseX, mouseY, partialTick)`; `renderBackground` → `extractBackground`; container screens use `extractLabels` / `extractSlot` / `extractContentSlots` |
| `Packet<ClientGamePacketListener?>` | the type parameter must satisfy `PacketListener`; drop the `?` |
| private/protected Minecraft members | add `transitive-accessible` widener entries in the `official` namespace; `aw_from_log.py` generates them from the CI log with real descriptors |
| `Feature<C>` + `FeaturePlaceContext<C>` + `configurations.*` | `Feature` is a non-generic interface: `codec(): MapCodec<out Feature>` and `place(WorldGenLevel, ChunkGenerator, RandomSource, BlockPos)`; the config becomes constructor state |
| `ConfiguredFeature` / `Registries.CONFIGURED_FEATURE` | gone; features are datapack entries in `Registries.FEATURE` (`worldgen/feature`), with `type` codecs in `BuiltInRegistries.FEATURE_TYPE` |
| `BuiltInRegistries.FEATURE` | `BuiltInRegistries.FEATURE_TYPE` (`Registry<MapCodec<out Feature>>`) |
| `TreeGrower(name, Optional, Optional, Optional)` | `TreeGrower(name, WeightedList<ResourceKey<Feature>> trees, megaTrees, flowerTrees, ResourceKey<Feature> shortestTreeType)` |
| `PlacementUtils.inlinePlaced(feature, config, vararg modifiers)` | `PlacementUtils.inlinePlaced(Holder<Feature>, List<PlacementModifier>)`; `SimpleBlockConfiguration` → `SimpleBlockFeature(provider)` |
| `BlockStateProvider.simple(state)` | `BlockStateProvider.of(state)` |
| `EntityType.PLAYER`-style constants | `EntityTypes.PLAYER` (`net.minecraft.world.entity.EntityTypes`) |
| `isPathfindable(state, level, pos, type)` | `isPathfindable(state, type)`; the shape/redstone overrides take non-null arguments |
| `InteractionResult.SUCCESS_NO_ITEM_USED` | `InteractionResult.SUCCESS_SERVER` |
| `Blocks.WHITE_CANDLE` … `Blocks.BLACK_CANDLE` | `Blocks.DYED_CANDLE.pick(DyeColor.WHITE)` (a `ColorCollection<Block>`) |
| `LecternBlock.SHAPE_COMMON/NORTH/…` | private; the shapes are now `LecternBlock.SHAPES : Map<Direction, VoxelShape>` (widened) |
| `Item#getEatingSound()` / `#getDrinkingSound()` | removed; the sound comes from `Consumable.Builder#sound(Holder<SoundEvent>)` |
| `SoundEvents.FOO` used as `SoundEvent` | some constants are `Holder.Reference<SoundEvent>`; unwrap with `.value()` (or use the `Holder` overload of `playSound`) |
| `BuiltInRegistries.SOUND_EVENT.get(id)` | returns `Optional<Holder.Reference<SoundEvent>>` |
| `LootItemBlockStatePropertyCondition.hasBlockStateProperties(block).setProperties(..)` | `MatchBlock.blockMatches(holderGetter, block, StatePropertiesPredicate.Builder)` |
| `IntRange.upperBound(n)` in `LimitCount` | `IntLimit.upperBound(n)` (`net.minecraft.world.level.storage.loot.IntLimit`) |
| `UniformGenerator.between(a, b)` / `ConstantValue.exactly(v)` | `ContextIntProviders.between(a, b)` / `ContextIntProviders.exactly(v)` (holders of `ContextIntProvider`); `SetItemCountFunction.setCount` takes that holder |
| `ItemPredicate.Builder#withSubPredicate(ItemSubPredicates.ENCHANTMENTS, ..)` | `withComponents(DataComponentMatchers(DataComponentExactPredicate.EMPTY, mapOf(DataComponentPredicates.ENCHANTMENTS to EnchantmentsPredicate.enchantments(..))))` |

## Still open (large, structural)

| 1.21 API | 26.3 model |
| --- | --- |
| `MultiBufferSource` / `VertexConsumer` immediate drawing | `EntityRenderer#submit(state, PoseStack, SubmitNodeCollector, CameraRenderState)` with extracted render states |
| `BlockEntityRenderer#render(...)` | `BlockEntityRenderer<T, S>` with `createRenderState` / `extractRenderState` / `submit` |
| `ItemColor` / `BlockColor` | `net.minecraft.client.color.item.ItemTintSource` / `block.BlockTintSource` |
| `RecipeBookComponent` screen integration | replaced tab/tabInfo API plus `RecipeBookMenu` generics |
| JEI screen hooks in `CookingPotScreen` | no JEI dependency in the 26.3 source set |

## Scripted batches (`fabric-26.3/build/ci/`)

All of these are idempotent and preserve CRLF line endings.

| Script | Purpose |
| --- | --- |
| `import_audit.py` | Audit every import against the 26.3 jar and list moved/removed classes with candidate packages |
| `batch_263_imports.py` | Rewrite the verified class moves (import lines and fully-qualified uses) |
| `batch_263_valueio.py` + `batch_263_valueio_manual.py` | Block entity save/load migration to `ValueOutput`/`ValueInput` |
| `batch_263_gui_pose.py` | Rewrite GUI 2D transforms; only receivers that provably come from `.pose()` are touched |
| `aw_from_log.py` | Generate access widener entries for every unreachable member in the build log |

## Workflow reminders

- Local builds are not possible here (no JDK 25). CI is authoritative.
- `python fabric-26.3/build/ci/fetch_ci.py <sha>` downloads the newest build log
  using the git credential token; `errors_for.py <substring>` prints per-file errors.

## Remaining diagnostic clusters

Ordered by size in run `39359114125`:

1. Render pipeline: `MultiBufferSource`/`getBuffer`/`RenderStateShard` and the old `RenderType` builders. Needs `SubmitNodeCollector` plus extracted render states (`EntityRenderer#submit`, `BlockEntityRenderer<T, S>`).
2. GUI drawing: helpers still declare `PoseStack` while `GuiGraphicsExtractor.pose()` returns `Matrix3x2fStack`; `GlStateManager`/`Tesselator`/`BufferUploader` usages.
3. GUI widget coordinates: 113 `Double`/`Float` mismatches across screens and widgets, plus the new `MouseButtonEvent`/`KeyEvent` and scroll APIs.
4. Block entity persistence: `saveAdditional`/`loadAdditional` now take `ValueOutput`/`ValueInput`, and `CompoundTag#writeBlockPos`/`readBlockPos` are gone.
5. Registry/item leftovers: `VillagerTrades.ItemsForEmeralds` and `VillagerTrades.ItemListing` (trades are data-driven `VillagerTrade` records now), `ItemColor`/`BlockColor` → `ItemTintSource`/`BlockTintSource`, smithing template data.
6. World generation: `FeaturePlaceContext` no longer exists; `Feature#place(WorldGenLevel, ChunkGenerator, RandomSource, BlockPos)` takes no configuration argument.
7. Entities/AI: boat entity, `NPCEntity`, `PokemonEntity` and brain/sensor API changes.

## Working notes

- 26.3 has no intermediary mapping layer, so the access widener stays in the `official` namespace.
- The de-obfuscated 26.3 API is available at `fabric-26.3/build/mcapi/minecraft.jar`; inspect it with `inspect.py`, `sig.py` (generic signatures) and `params.py` (parameter names) before editing a call site. See `AGENTS.md` for the full workflow.

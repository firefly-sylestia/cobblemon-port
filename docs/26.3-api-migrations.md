# 26.3 API migration notes

Mapping of Minecraft 1.21-era APIs to their 26.3 replacements, kept so the same
substitution can be applied quickly across the tree. Verified against
`fabric-26.3/build/mcapi/minecraft.jar` with `fabric-26.3/build/mcapi/inspect.py`.

## Applied (see `fabric-26.3/build/ci/api_map.py`)

| 1.21 API | 26.3 replacement |
| --- | --- |
| `BlockBehaviour#codec()`, `simpleCodec()`, `propertiesCodec()` | removed for blocks; delete block `CODEC`/`codec()` members |
| `Block#updateShape(state, direction, neighborState, world: LevelAccessor, pos, neighborPos)` | `updateShape(state, level: LevelReader, ticks: ScheduledTickAccess, pos, directionToNeighbour, neighbourPos, neighbourState, random: RandomSource)` |
| `Block#onRemove(state, level: Level, pos, newState, movedByPiston)` | `affectNeighborsAfterRemoval(state, level: ServerLevel, pos, movedByPiston)` (no `newState`) |
| `Containers.dropContentsOnDestroy(state, newState, level, pos)` | `Containers.dropContents(level, pos, container)` |
| `net.minecraft.world.item.UseAnim` | `net.minecraft.world.item.ItemUseAnimation` |
| `InputConstants.Type.KEYSYM` | `InputConstants.Type.KEYBOARD` |
| `net.minecraft.client.renderer.LightTexture.pack(b, s)` | `net.minecraft.util.LightCoordsUtil.pack(b, s)` |
| `GuiGraphics#renderTooltip(...)` | `GuiGraphicsExtractor#setTooltipForNextFrame(...)` |
| `BlockPos#bottomCenter` | `Vec3.atBottomCenterOf(pos)` |
| `DirectionProperty` | `EnumProperty<Direction>`, `EnumProperty.create(name, Direction::class.java)` |
| `RenderType.entityCutout/entitySolid/entityTranslucent/beaconBeam/waterMask/text/lightning(..)` | `RenderTypes.<same>(..)` in `net.minecraft.client.renderer.rendertype` |
| `Block#getCloneItemStack(level, pos, state)` | `getCloneItemStack(level, pos, state, includeData: Boolean)` |
| `Block#neighborChanged(state, level, pos, block, direction, moved)` | `neighborChanged(state, level, pos, block, orientation: Orientation, moved)` |
| `net.minecraft.advancements.critereon.*` | split: `net.minecraft.advancements.predicates.*` (predicates, `StatePropertiesPredicate`, `MinMaxBounds`) and `net.minecraft.advancements.triggers.*` (`CriterionTrigger`, `CriteriaTriggers`, `SimpleCriterionTrigger`) |
| `CriterionTrigger` / `SimpleCriterionTrigger<T, C>` | `CriterionTrigger<T : CriterionTriggerInstance>`; `SimpleCriterionTrigger<T : SimpleCriterionTrigger.SimpleInstance>`, `codec()` now declared by the interface |
| `SimpleCriterionTrigger.SimpleInstance#player()` returning `Optional<EntityPredicate>` | returns `Optional<Holder<LootItemCondition>>`; `EntityPredicate.wrap(...)` already produces that |
| `BuiltInRegistries.ENTITY_SUB_PREDICATE_TYPE` holding `MapCodec` | still `Registry<Codec<out EntitySubPredicate>>` |
| `ItemPredicate.Builder#of(item)` / `of(tag)` | `of(HolderGetter<Item>, itemLike)` / `of(HolderGetter<Item>, TagKey<Item>)` |
| `ItemPredicate.Builder#withSubPredicate(ItemSubPredicates.CUSTOM_DATA, ItemCustomDataPredicate(nbt))` | `withComponents(DataComponentMatchers(DataComponentExactPredicate.EMPTY, mapOf(DataComponentPredicates.CUSTOM_DATA to CustomDataPredicate(nbt))))` |

## Still open (large, structural)

| 1.21 API | 26.3 model |
| --- | --- |
| `MultiBufferSource` / `VertexConsumer` immediate drawing | `EntityRenderer#submit(state, PoseStack, SubmitNodeCollector, CameraRenderState)` with extracted render states |
| `BlockEntityRenderer#render(...)` | `BlockEntityRenderer<T, S>` with `createRenderState` / `extractRenderState` / `submit` |
| `ItemColor` / `BlockColor` | `net.minecraft.client.color.item.ItemTintSource` / `block.BlockTintSource` |
| `RecipeBookComponent` screen integration | replaced tab/tabInfo API plus `RecipeBookMenu` generics |
| JEI screen hooks in `CookingPotScreen` | no JEI dependency in the 26.3 source set |

## Workflow reminders

- Local builds are not possible here (no JDK 25). CI is authoritative.
- `python fabric-26.3/build/ci/fetch_ci.py <sha>` downloads the newest build log
  using the git credential token; `errors_for.py <substring>` prints per-file errors.

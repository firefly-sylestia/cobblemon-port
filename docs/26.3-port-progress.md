## Remaining diagnostic clusters

Ordered by size in run `39367960166`:

1. Render pipeline: `MultiBufferSource`/`getBuffer` and the submit-node architecture. `PosableModel`, the render layers, entity renderers and block entity renderers all need `SubmitNodeCollector` and extracted render states.
2. GUI screens: the cooking pot screen/menu (`RecipeBookMenu` lost its type parameters and placement moved to `ServerPlaceRecipe.placeRecipe`), `StateSwitchingButton` removal, JEI hooks in common code.
3. Recipes: `Recipe` is no longer generic (`matches(RecipeInput, Level)`, `assemble(RecipeInput)`, `placementInfo()`, `recipeBookCategory()`) and `RecipeSerializer` is a record of `(MapCodec, StreamCodec)`. Affects `CookingPotRecipeBase`, `CookingPotShapelessRecipe`, `BrewingStandRecipe`.
4. Particle rendering: `ParticleRenderType` is a record of (name, shorthand) and quad rendering moved to render states.
5. Tint sources: `ItemTintSource` / `BlockTintSource` implementations and their `type()` codecs.
6. Villager trades: trades are data-driven `VillagerTrade` records registered through `TradeSet`; `TradeOfferHelper` and `VillagerTrades.ItemListing` are gone.

## Working notes

- 26.3 has no intermediary mapping layer, so the access widener stays in the `official` namespace.
- The de-obfuscated 26.3 API is available at `fabric-26.3/build/mcapi/minecraft.jar`; inspect it with `inspect.py`, `sig.py` (generic signatures) and `params.py` (parameter names) before editing a call site. See `AGENTS.md` for the full workflow.
- Batch scripts live in `fabric-26.3/build/ci/` and are idempotent and CRLF-safe; see `docs/26.3-api-migrations.md`.

## CI log retention

The workflow artifact `fabric-26.3-build-log` contains the complete log and a compact diagnostics report and is retained for 14 days. The workflow also publishes the first compiler errors and diagnostic totals as check annotations, because downloading logs and artifacts requires repository write access.
